**What does this mod do?**<br>
This mod backports the new tick command added in 1.20.3.<br>
The /tick command provides utilities for modifying the target tick rate of the game, temporarily fast forwarding the game, and pausing the game server side among other things.<br>
The command format is the same as in 1.20.3:<br>
