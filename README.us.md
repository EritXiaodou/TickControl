**What does this mod do**<br>
It brings the tick command introduced in 1.20.3 to 1.20.1-neoforge, 1.20.1-forge, 1.19.2-forge, 1.18.2-forge, 1.17.1-forge, 1.16.5-forge, 1.12.2-forge, and 1.7.10-forge.<br>

For 1.12.2, there are two versions:<br>
- One with built-in mixin<br>
- One using mixinbooter<br>
Both can be added at the same time. When added together, the built-in mixin has a lower priority, and the mixin booter loads first.<br>

If you download the mixinbooter version, make sure to install mixinbooter as a dependency. If you download the built-in mixin version, you can ignore this.<br>
